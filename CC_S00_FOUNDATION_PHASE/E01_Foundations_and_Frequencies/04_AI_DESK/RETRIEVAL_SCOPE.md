# S00E01 AI Desk Retrieval Scope

## Current episode

Use first for episode-specific facts.

## Current season

Use for Foundation Phase continuity and recurring concepts.

## All approved episodes

Use only approved/archived material for continuity.

## Global Chronicles

Use for long-term character and world references.

## Consent rule

Community/member content must be excluded unless the current consent state authorizes Chronicle use.

## Failure rule

If a source is unavailable or permission cannot be verified, return a controlled `SOURCE_UNAVAILABLE` / `CONSENT_REQUIRED` state rather than inventing content.
