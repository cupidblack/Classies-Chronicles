# Classies Chronicles — S00E01 Pilot Foundation Package

## Season
**S00 — The Foundation Phase**

## Episode
**S00E01 — Foundations & Frequencies**

## Chronicle
**The Signal Before the Story**

## Package purpose
This package is a refactored, production-ready working package for the first Foundation Phase pilot episode. It is intentionally a **focused episode package**, not a mirror of the entire Classies Chronicles repository.

The package establishes:
- a canonical Cupid Black character reference;
- a canonical EduBeam technology reference;
- a reusable episode-generation contract;
- episode context and continuity controls;
- current-news provenance with future-date safeguards;
- a Chronicle-first workflow;
- a 200-second Chronicle;
- a 20-second trailer derived from the Chronicle;
- a podcast rundown;
- a production checklist;
- repository hygiene rules.

## Core creative decision
The pilot's main story is:

> **A trustworthy foundation must be built before the strange signal can be understood.**

The audience first experiences the 9 July 2026 Singapore EduBeam event through Enka's perspective, then returns to the present-day Foundation Phase where the Koware Group / Buzzjuice Network / Buzzjuice Courses ecosystem is introduced.

The episode does **not** attempt to reveal the complete superhero origin. It creates the mystery that later episodes can answer.

## Canon discipline
The package uses the following authority order:

1. Approved Classies Chronicles archive
2. Reusable character and technology canon
3. Episode context
4. Producer story notes
5. Working interpretation / speculation

Anything newly proposed is explicitly marked as `PROPOSED_NEW_CANON` until producer approval.

## Real-world vs fiction
EduBeam, Cupid Black's abilities, and all supernatural/technological effects are fictional story devices. Real news is kept separate from the fictional Chronicle and must never be represented as being caused by EduBeam.

## Important date limitation
The production brief requested news from **9 August 2026 through 17 October 2026**. The current package was prepared on **31 August 2026**, so news after 31 August 2026 cannot yet be procured. Future dates are therefore marked `PENDING_FUTURE_RETRIEVAL` rather than fabricated.

## Recommended production sequence
1. Lock episode context.
2. Verify continuity.
3. Lock the Chronicle.
4. Generate and review the 20-second trailer from the locked Chronicle.
5. Record the podcast.
6. Run ENVY/Pavilion and AI co-host checks.
7. Edit and review narration.
8. Complete final QA.
9. Archive the release package.
