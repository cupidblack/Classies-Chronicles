## What this package does
This is a ready-to-review working-tree package for S00E01. It refactors the episode around the existing archive continuity, the current studio architecture, the persistent AI Desk concept, and a stricter canon/provenance model.

It is intentionally **not a GitHub push**. Review, copy/merge, test and commit it to the repository after producer approval.

## Main creative decision
**Key topic:** *Build the foundation before trying to control the signal.*

The first episode should not explain Cupid Black's complete origin. It should make the audience curious while simultaneously introducing Koware Group, Buzzjuice Network, Buzzjuice Courses and the Foundation Phase.

## Important corrections
1. The requested headline window ends 2026-10-17, but today's commissioning cutoff is 2026-08-31. Future headlines are therefore marked **PENDING** rather than fabricated.
2. E01 does not establish mastered teleportation, phasing, telepathy, telekinesis, dimensional travel, drone-beam replication, or exact brainwave targeting.
3. The EduBeam is explicitly fictional and is never presented as real neuroscience or technology.
4. Real-world news and fictional Chronicle events remain clearly separated.
5. The 20-second trailer is derived from the locked 200-second Chronicle rather than becoming a source of new canon.
6. AI remains assistive and controlled; human editorial, consent, licensing and publication authority remain final.
